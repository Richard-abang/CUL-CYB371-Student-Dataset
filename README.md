# Fictional Student Dataset

**Course:** CUL-CYB 371 – Data Mining and Data Warehousing  
**Assignment:** Assignment Two

## Description
This project contains a fictional dataset of 15 students. It includes each student's ID, department, level, attendance percentage, and average examination score.

All records are invented for academic demonstration. They do not represent real students.

## Files
- `create_dataset.py` – Python program that creates the dataset.
- `student_dataset.csv` – Dataset output; can be opened in Excel or a text editor.

## How to run
1. Make sure Python 3 is installed.
2. Open a terminal or command prompt in this folder.
3. Run:

   ```bash
   python create_dataset.py
   ```

4. The program creates `student_dataset.csv` in the same folder.

## Dataset fields
- Student ID
- Department
- Level
- Attendance Percentage
- Average Examination Score
